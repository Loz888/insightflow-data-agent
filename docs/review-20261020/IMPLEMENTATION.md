## 评分语义与历史重算

- 文本 `001` 与 `1` 不等；bool 不当 int，NULL 不当 0，文本日期/编码精确比较。
- 数值只有独立参考的列类型契约可以触发容差；不从模型 SQL 或实际值猜类型。
- `[9.999999999,2]` 与 `[10,2]` 在原容差内匹配；重复行保留次数，增广路径避免贪心错配，ordered=True 保持顺序。
- 原 30 题答案文件不改。旧历史记录没有 OID，离线重算使用冻结的三种受支持指标结果布局：数值 value、文本 dimension+数值 value、三个数值比较字段。
- [历史重算](../../reports/review-20261020/scorer-replay.json)：206 次结果比较、330 次跨快照比较，变化 0。每个输入文件有 SHA-256，原文件不写入。
- 重算只处理可重建的结果比较；不从缺失轨迹重新制造 warmup、语义/自然语言或 E2E 证明。这个结果不表示新增真实模型准确率。

## 升级与边界

- 本轮没有新增 Python 数据库迁移；复用已迁移的会话与 graph_threads。先排空/停止旧 API 实例，再启动新版本；未实现新旧 Worker 按入队版本自动路由，不能宣称无缝滚动升级。
- 旧 Checkpoint 不重标版本、不自动重放；需要显式核对/迁移，或用新 Run 开始。已完成记录和历史会话不因升级删除。
- V1 仍是旧行为基线，旧真实理解入口不等于 V2；本轮不把其规则/Plan 大改成另一套应用。
- 新增守卫覆盖可识别条件，不能证明任意中文理解正确。每约束的来源、确认、撤销/遗忘生命周期仍是 3.7 / I1 的后续工作。
- 确定性 SQL 编译对照、大 Schema 独立检索 Gold 与 30–60 条挑战集仍待推进；已有 30 表夹具不等于已证明大规模 RAG 收益。
- 付费结果未知时仍保守阻止自动重放，不声称 Exactly-once。Docker 实际运行无引擎仍 BLOCKED，SSO、完整保留策略及生产 SLA 未验收。

本轮按报告第一轮完成并保留证据；不同时扩展 MCP、多 Agent、长期画像或跨项目调度。
