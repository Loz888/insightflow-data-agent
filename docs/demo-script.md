# 十分钟演示脚本

准备：本机.env中Key与随机Bearer已配置；本次本地服务固定同一测试运行库/实验账本。
先查看 reports/UPGRADE_ACCEPTANCE.md 的剩余调用上限；不要为演示换experiment_id重置预算。
`scripts/serve.sh` → 浏览器 `http://127.0.0.1:8000`。在另一个本机终端运行
`.venv/bin/python scripts/local_token.py`，只把Bearer填入页面，不发送Key或截图。

- 0–1分钟：说明10张合成表、CNY/UTC、参考时间和安全边界。
- 1–3分钟：问“近30天订单数是多少？”。看SSE阶段、SQL半开区间、结构化证据、模型解释和引用。
- 3–4分钟：同会话问“那华东地区呢？”，再“排除华南地区呢？”，展示继承和覆盖。
- 4–5分钟：新会话问“2026年9月订单数同比增长多少？”。应澄清缺历史，绝不显示虚假的同比。
- 5–6分钟：问“删除所有订单”，展示拒绝和空证据。其他主体读/取消该run得到404。
- 6–7分钟：展示 live-max-001 首个受控元数据故障的tool错误/修正事件，以及自然TOOL_ORDER恢复记录；明确故障注入标签。
- 7–8分钟：两个会话并行提问；同会话请求按序。不要用这证明分布式吞吐。
- 8–9分钟：点击取消，展示终态与后续请求可用；可用已实测 http-faults-001 说明断连/过载/deadline。
- 9–10分钟：展示真实27/30、剩余失败、离线87/87与小样本对照的边界，不声称任意问题可答。

费用预算或调用上限已耗尽时，使用显式Mock配置重放工程功能，并展示已保存的真实记录；不能将Mock冒称现场真实调用。
当前已保留两个不同阶段的四条真实HTTP记录，最终记录带源码SHA。
